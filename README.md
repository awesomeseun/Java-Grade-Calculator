# Java Student Grade Calculator

A Java console application that calculates a student's weighted course average and letter grade.

## Grade Weights

- Homework: 30%
- Quizzes: 20%
- Exams: 50%

## Features

- Accepts multiple grades
- Calculates category averages
- Calculates weighted final grade
- Converts numerical grades to letter grades
- Validates user input
- Handles invalid entries

## Technologies

- Java
- Methods
- Loops
- Conditional Statements
- Exception Handling
- Git
- GitHub

## How to Run

Compile:

javac GradeCalculator.java

Run:

java GradeCalculator
